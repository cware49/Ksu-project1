Research Project Overview

Abstract

This project explores fundamental technologies and practices in web development. The goal is to document research on current tools, standards, and techniques used to build modern websites.

Key Terms

  • HTML5: HyperText Markup Language used for structuring web content.
  • CSS3: Cascading Style Sheets used for styling and layout.
  • Responsive Design: Designing websites to work across different screen sizes.
