Subtopic 2: Layout Systems

Modern CSS provides powerful tools for creating responsive site layouts without relying on external frameworks.

Layout Methods

  • Flexbox: Ideal for one-dimensional layouts (rows or columns). Commonly used for navigation bars and buttons.
  • CSS Grid: Ideal for two-dimensional layouts (rows and columns simultaneously). Best for overall page structures and complex design grids.

Key Research Concepts

  1. Semantic HTML: Using element tags that clearly describe their meaning to both the browser and the developer (e.g., <header>, <article>, <footer>).
  2. CSS Box Model: The conceptual model wrapping every HTML element, consisting of content, padding, border, and margin.
  3. DOM (Document Object Model): The programming interface for web documents that represents the page structure as a tree of nodes.
  4. Web Accessibility (a11y): The practice of making web content accessible to all users, including those with disabilities.
  5. Cross-Browser Compatibility: Ensuring web application content displays consistently across different web browsers.
