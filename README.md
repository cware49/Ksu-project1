Web Development Research Project

Project Overview

This project was created for IT 3203 – Web Development at Kennesaw State University.

The purpose of this project is to research and demonstrate fundamental web development technologies, including HTML, CSS, JavaScript, and responsive web design.

The website provides educational information about frontend technologies, responsive layouts, and important web development concepts. It also includes an interactive quiz that allows visitors to test their understanding of the material.

Technologies Used

* HTML5: Structures website content and individual pages.
* CSS3: Controls website styling, layout, colors, and responsive design.
* JavaScript: Adds interactive functionality and handles quiz grading.
* GitHub: Stores project files and tracks development changes.
* GitHub Pages: Publishes the website online.

Website Pages

The website contains the following pages:

Page	Description

Quiz	Provides an interactive knowledge assessment.

Interactive Quiz Features

The quiz was developed using HTML and JavaScript.

It includes:

* Ten questions covering web development topics.
* Fill-in-the-blank questions.
* Multiple-choice questions.
* Multiple-selection questions.
* True-or-false questions.
* A ten-minute countdown timer.
* Automatic grading and percentage calculations.
* Pass/fail results based on a 70% passing score.
* Individual question feedback and correct answers.
* Recorded quiz completion time.
* Reset and retake functionality.

Website Design

The website uses a shared CSS stylesheet to maintain consistent styling across its pages.

Design features include:

* Consistent navigation menus.
* Blue and white color scheme.
* Organized content sections.
* Styled quiz question cards.
* Visual feedback for correct and incorrect answers.
* Responsive layouts for smaller screens.
